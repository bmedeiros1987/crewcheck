# TV Core — experimental

Canonical roster is projected by `projectRoster`; the existing canonical builder and selector remain the sole domain engines. Empty dates mean **no published activity**, never inferred days off. Monthly navigation groups canonical events for display without merging journeys. Family projections remove routes and flight numbers before delivery.

`leaveAt`, gate, weather, changes and ticker must be populated by authorized existing operational projections, with provenance and expiry. They are deliberately unavailable when that integration has no evidence. News is a separate editorial response and cannot populate these fields.

Release remains blocked by #530/#607 and physical validation. This package alone does not enable any server route.
