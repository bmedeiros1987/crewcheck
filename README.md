# CrewCheck v11.1.08 · Telegram METAR Fonético + Voice Note Natural

Correção cumulativa sobre a v11.1.07.

## Correção principal

- Perguntas por áudio/texto com METAR, TAF, SIGMET, ATIS, meteorologia, vento, teto ou visibilidade agora têm prioridade sobre a intenção de escala.
- O bot reconhece ICAO direto, IATA conhecido e alfabeto fonético/NATO.
- Exemplo: “METAR de Sierra Bravo Bravo Romeo” vira SBBR e consulta meteorologia, não programação de hoje.
- Modo ATIS continua reservado para Meteorologia/METAR/TAF.
- Voice note mantém tom natural, de amigo, sem boletim para escala.
