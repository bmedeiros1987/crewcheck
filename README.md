# CrewCheck — Last Versions

Branch criada para o Codex comparar versões antigas do CrewCheck e restaurar funcionalidades perdidas.

## Objetivo

Usar estes ZIPs como referência histórica para a reconstrução v13 Restore Total.

## Estratégia recomendada

1. Comparar a versão atual com as versões antigas.
2. Identificar funcionalidades removidas.
3. Restaurar módulos reais, não cards mockados.
4. Preservar o layout Premium/EFB atual.
5. Corrigir parser, cronologia, escala, financeiro, rotina, despertador, meteorologia, radar, hotéis e admin.
