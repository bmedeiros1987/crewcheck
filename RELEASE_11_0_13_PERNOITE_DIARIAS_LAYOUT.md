# CrewCheck v11.0.13 — Diárias de pernoite fora de base + chips financeiros premium

## Correções

- Corrigido cálculo de diárias para inativo/pernoite fora de base.
- Dias de chegada/fim de jornada fora de base agora computam almoço e jantar quando o tripulante permanece fora da base.
- Ceia continua restrita a voo/reserva/jornada ativa cruzando 00:00–01:00; pernoite puro não gera ceia.
- Café continua sem entrar por pernoite puro, evitando falso positivo quando houver hotel.
- Base virtual e pernoite dirigido não geram diária automática.
- Cards financeiros pequenos da escala foram redesenhados para ficarem legíveis no tema escuro e claro.
