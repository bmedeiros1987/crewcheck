# CrewCheck v11.0.10 — Conversor de moedas e localização do carro

Versão focada em ferramentas de apoio ao tripulante:

- Novo módulo **Conversor de moedas**.
- Cotação do dia via backend `/api/exchange-rates`.
- Conversão rápida entre BRL, USD, EUR, GBP, ARS, CLP, COP, PEN, MXN e CAD.
- Diárias internacionais da escala convertidas para BRL como referência.
- Novo módulo **Onde estacionei**.
- Salva localização GPS do carro, precisão, terminal, piso, setor, fileira/vaga e observação.
- Link para abrir o ponto salvo no Google Maps.
- Compartilhamento/cópia do local salvo.
- Dados do estacionamento salvos por usuário no dispositivo.
- Menu Cockpit e Mais funções atualizados com Moedas e Meu carro.
- Mantido visual premium e wallpaper aeronáutico discreto.

Validação:

- `npm run check`
- `npm run build`
