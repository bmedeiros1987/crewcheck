# CrewCheck v13 — Módulos Operacionais

## Despertador Inteligente

Restaurar:
- ligação/VOIP;
- Telegram;
- ligação + Telegram;
- somente Telegram;
- somente ligação;
- confirmação de acordado;
- repetição escalonada;
- horário recomendado para dormir;
- replanejamento por atraso;
- menu exclusivo em Operacional.

Não expor nomes de API ao usuário. Usar termos genéricos:
- Ligação;
- Telegram;
- VOIP;
- Concierge.

## Saída Inteligente

Considerar apenas programações com deslocamento.

Mensagem:
- "Saia hoje às HH:MM"
- "Saia no dia DD/MM às HH:MM"

Fora de base:
- usar 1h antes da decolagem apenas quando não houver apresentação publicada confiável.

Escala:
- sempre mostrar horário publicado, sem inventar apresentação.
