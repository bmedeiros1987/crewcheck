# CrewCheck v13 — UI Premium/EFB

## Objetivo visual

Layout Premium, operacional, denso e legível.

Inspirar em:
- EFB;
- ForeFlight;
- Garmin Pilot;
- FlightDeck;
- portais profissionais de tripulação.

## Regras

- Não criar layout bonito e vazio.
- Toda tela precisa ter ação.
- Priorizar informação útil.
- Evitar cards genéricos.
- Não esconder funcionalidade antiga.
- Tema claro e escuro com contraste real.
- Sem overflow horizontal em mobile/iPad.
- Botões não podem ser cobertos pelo menu inferior.
- Menu admin apenas para admin.
- Versão no menu, não no rodapé.

## Cockpit

Deve mostrar:
- próxima programação correta;
- status de importação;
- alerta de escala;
- radar;
- meteorologia;
- diárias;
- salário;
- saída inteligente;
- despertador;
- rotina.

## Roster/EFB

Cada voo deve parecer um mini briefing:
- voo;
- origem/destino;
- apresentação/decolagem/chegada;
- tripulação;
- aeronave;
- portão;
- terminal;
- METAR/TAF;
- hotel;
- tempo de solo;
- ações.

## Acessibilidade

- textos pequenos precisam ser legíveis;
- chips com alto contraste;
- botões claros;
- modo claro não pode ter texto apagado;
- modo escuro não pode esconder informação.
