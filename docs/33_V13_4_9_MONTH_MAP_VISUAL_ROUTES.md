# CrewCheck v13.4.9 — Monthly Map / Visual Routes

## Objetivo

Separar visualmente mapa, rota, malha viária e trânsito para evitar confusão operacional.

## Inclui

- Mapa do mês com todos os destinos publicados na escala.
- Linhas visuais de voo por aeroporto de origem/destino.
- Estimativa visual de quilometragem mensal.
- Representação visual hotel/localização → aeroporto.
- Meu Carro com rota, estacionamento e pós-pouso.
- Acesso à malha viária/POIs próximos via OSM/Overpass.
- Mapa usado apenas para visualização de rota.
- Trânsito em tempo real tratado como serviço separado quando disponível.

## Observação técnica

OSM/Overpass não fornece trânsito em tempo real. Ele é usado apenas para malha viária e pontos próximos, como estacionamento, combustível e táxi. O tempo de trânsito real deve continuar separado de mapa visual e depender de serviço específico configurado.

## Preservado

- Parser AIMS/CrewRoster.
- Motor canônico.
- Continuidade física.
- Import Guardian.
- Lounge Systems Restore.
- Version Badge Restore.
- Layout Premium/EFB.
- Sem credenciais, senha, MFA, SMS, cookies ou sessão.
