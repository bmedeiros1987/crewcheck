# CrewCheck v13 — Master Specification

## Visão

CrewCheck é uma ferramenta operacional para tripulantes. O app deve importar, interpretar, explicar, sincronizar e operacionalizar a escala.

O layout desejado é Premium/EFB, inspirado em ferramentas profissionais de aviação: informações densas, claras, acionáveis e confiáveis.

## Estrutura de navegação

### Cockpit
Tela inicial operacional:
- Próxima Programação;
- Saída Inteligente;
- Radar do próximo voo;
- METAR/TAF da origem e destino;
- alerta de irregularidade;
- salário previsto;
- diárias previstas;
- despertador ativo;
- rotina ativa;
- botão importar escala;
- botão exportar calendário.

### Escala
Roster completo:
- cards por dia;
- cards por voo;
- apresentação;
- decolagem;
- chegada;
- etapa;
- tipo de programação;
- tripulação;
- hotel;
- tempo de solo;
- pernoite;
- pernoite diurno;
- irregularidades;
- meteorologia;
- radar;
- exportação;
- compartilhamento.

### Operacional
- Despertador Inteligente;
- Rotina;
- Meteorologia;
- Radar;
- Hotéis;
- Transporte;
- Regulamentação;
- Concierge.

### Financeiro
- Diárias;
- Salário;
- histórico;
- recebido versus previsto;
- diferenças.

### Admin
Visível somente para administrador:
- C32F;
- painel admin;
- ferramentas de diagnóstico;
- logs seguros sem dados sensíveis.

## Regra de ouro

Nenhuma tela deve existir apenas para mostrar informação. Cada tela deve permitir uma ação operacional útil.
