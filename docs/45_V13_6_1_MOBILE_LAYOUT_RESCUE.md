# CrewCheck v13.6.1 — Mobile Layout Rescue / Premium Overflow Fix

## Objetivo
Corrigir regressões visuais críticas no mobile sem mexer nos motores operacionais.

## Corrige
- Cards maiores que a tela.
- Textos quebrando letra por letra.
- Chips/círculos comprimidos.
- Gate/status estourando.
- Cards da escala com conteúdo vertical.
- Bottom nav cobrindo conteúdo.
- Botões largos demais.
- Mapas e iframes fora da área útil.
- Tabelas derrubando o layout.
- Tema claro/escuro com contraste reforçado.

## Preservado
- Parser AIMS/CrewRoster.
- Motor canônico.
- Continuidade física/anti-teletransporte.
- Radar multi-API.
- Google Calendar.
- Mapas.
- Previsão de pernoite.
- Diárias/salário.
- Regulamentação.

## Observação
Esta versão é um hotfix visual emergencial. Não reescreve componentes nem altera regras de negócio.
