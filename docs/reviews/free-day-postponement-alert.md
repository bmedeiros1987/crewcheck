Compare only authenticated owner-v2 planned reference and an owner-bound current roster of the same month, crew identity and base. Visitors, unowned legacy snapshots, audit mode, empty data and missing/ambiguous literal start or published timezone cannot emit an alert. No midnight, arrival-plus-rest or duty-report fallback is used. Human and visual AIMS producers preserve the first clock immediately after the rest code; exact date/code visual candidates restore metadata after canonical rest normalization without changing the selected days, numeric clocks, flights or remuneration.

A consecutive DO/DR sequence produces one evaluation. Version corrections remain in the owner-scoped history; sequence + source versions deduplicate. ## Existing ACT and qualification

Clause 3.4.4 sections1–6: more than four hours under ordinary conditions, more than twelve only with documented adverse weather, unscheduled maintenance, catastrophe or infrastructure imperative necessity; administrative failures do not establish that exception. One indemnity per consecutive sequence. Reuse existing compensationPolicy.freeDayPostponementIndemnity; no new rate or salary rule. Profile and ACT period must apply. ## Channel and delivery

Use existing Pulse and device Notification API only. Never request permission, enable preferences, send actual messages or add transport/credentials. External request requires pre-existing device preference, granted permission and cross-tab Web Locks for deduplication. No supported lock or no prior permission means unavailable/not sent. Storage reservation precedes dispatch; failure stops it. Recheck captured owner/session before dispatch and after waiting for locks. OS API acceptance is accepted_unconfirmed and delivered:false, not a receipt. History cannot establish historical external delivery. No automatic retry of a reserved version.
