# ASB flight-block ownership: factual reader correction

Base: e729566dd7fdaeee4da9eb1a1954d3ae5b240d35 (#1127).

A published ASB row can contain multiple canonical journeys. The shared measurement reader applied the earlier reserve's 03:00 report to a later block with its own published 15:00 APZ. This affected factual duration and totals as well as Next/Departure. The initial fix dd47183b used legIndex and was rejected in independent review: partial duplicates made ownership order-dependent, physical filtering reindexed a later flight to zero, and an explicit leg APZ could promote an estimated/unknown row report.

The revised reader identifies replicas by physical flight occurrence (date, flight number, route and literal flight clocks), then checks original pre-filter clock evidence across every replica and preserved record. A unique original clock pair must establish the opening flight of every record before the row's reserve contribution is admitted; row reports and sources must agree and be published. Evidence that a complete source row places the flight later defeats a partial duplicate that starts there. Missing or ambiguous evidence leaves full duration pending. Index after normalization is not ownership.

An independently published leg APZ remains available as a boundary when full reserve duration is pending; it does not turn estimated/unknown reserve hours into a published integral duration. When original evidence establishes the selected flight as a later block, its own APZ and published release measure that block. No other journey's reserve hours are added.

Independent review and CI on the revised HEAD are required before merge. Changes are restricted to the shared factual reader, synthetic tests and this report: no classifier/parser, regulatory formula, financial writer, authentication or transport changes. No real Telegram/provider messages or data were used. Menu/hospital work remains paused.

Synthetic validation includes raw/prepared real Next/Departure readers, actual duty-facts consumer, canonical measurement and existing shared total consumer. Tests select the intended flight by stable flight number, cover full/partial source permutations, disconnected first-leg removal and reindexing, absence of a second APZ, estimated/unknown/absent report provenance, conflicting duplicate sources, source immutability, ordinary date/year boundary, and four process timezones. Existing first-bound reserve, overnight, deduplication and source-proof controls remain.

Counterproofs on dd47183b: 9 of 13 new prepared Departure cases fail, factual cases fail, and the corrected identity-selected measurement suite fails. Revised result counts and exact source artifact are in the delivery report. This is a separate inherited P1 from #1127's route fallback date formatting; it does not establish that every APZ case is fixed. #1115 stays contract-only; financial data synchronization remains unavailable.

## Second independent HOLD: normalized clocks and nested evidence

Review of ca6920ba found that raw clock-string comparisons excluded equivalent replicas (08:00/09:00 versus 8:00/9:00), and a one-level records reader ignored nested estimated provenance or an earlier original flight block. Both affects factual measurement/endpoints and real Next/Departure consumers; the nested earlier-block case also affects the factual adapter. The raw and prepared real-reader counterproof reproduces three failures out of four. Depth-two preserved evidence is covered as an accepted input shape; no claim is made that common imports generate that depth.

The revised reserve proof normalizes clocks before identity/ownership comparisons, retaining explicit civil-day offsets as part of identity. It reads each container and descendant record, rejects malformed/incomplete clocks, and preserves all provenance uncertainty. Traversal is bounded to 4,440 visits and clock entries and depth 64, with active-path cycle detection. Budget exhaustion never grants proof. Equivalent parent duplicate clocks are allowed only as an aggregate container; original leaf records must uniquely identify the flight. Conflicting literal APZ is unavailable rather than selected by source order. Reserve flight-clock bounds use the same guards.

New regressions cover clock-equivalent full/partial source permutations, nested estimated and earlier-block records, nested missing clocks, cycles, excessive depth and node budgets, with real measurement/endpoints, shared totals, factual review and Next/Departure in raw and prepared forms.
