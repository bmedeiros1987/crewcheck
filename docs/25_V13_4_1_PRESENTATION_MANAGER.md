# CrewCheck v13.4.1 — Gerenciador de Apresentação

## Objetivo

Trazer de volta o Gerenciador de Apresentação, com aprendizado progressivo por hotel/local e possibilidade de ajuste manual.

## Inclui

- Menu dedicado: `Gerenciador de Apresentação`.
- Ajuste manual por programação.
- Salvar horário como padrão do hotel/local.
- Aprendizado local com confiança e número de amostras.
- Aplicação automática do horário aprendido nos próximos cards.
- Limpeza de ajuste manual.
- Limpeza de aprendizado do hotel/local.
- Integração opcional com o detalhe premium da programação v13.4.0.

## Privacidade

- Dados ficam no armazenamento local do app.
- Não salva credenciais, senha, MFA, SMS, cookies ou sessão.
- Não depende de API externa.

## Preservado

- Motor canônico da escala.
- Parser AIMS/CrewRoster.
- Continuidade física.
- Layout Premium/EFB.
