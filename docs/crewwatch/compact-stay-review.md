# Compact stay presentation — review candidate

The active stay view displays Pernoite, airport, hotel APZ and its supplied civil date. Hotel and timezone move to a scrollable details view. The existing snapshot contains no room; this change adds none. It does not calculate APZ, infer a date, alter phone projection, transport, admission, consent or release policy.

The scrollbar reuses the independent visible/fading/inside-overlay change from PR #836. Existing WatchViewport geometry from #1044 stays intact. The details button replaces the former route to the generic schedule. The operational complication also opens the matching stay details. Both paths reload the existing secure cache and require the same context and generation, fresh and still in OVERNIGHT. Revocation, a new generation, another occurrence or expiry yields only Pernoite indisponível and Voltar. The Intent carries identity/generation, never hotel or room. PendingIntent identity uses a digest URI: extras alone would allow FLAG_UPDATE_CURRENT to retarget an old card to a new occurrence. Preview cards do not carry a live target.

Only the existing APZ hotel date/time/timezone label is formatted; UTC and IANA zones work. Missing, legacy pickup and invalid values remain APZ —; airport/flight presentation is never substituted. Civil date stays visible on the compact view and complication. The received hotel remains subject to the existing 24-character producer/receiver limit; this UI change does not expand that transport contract or claim to recover a full name.

Validation: JVM cases cover absent/invalid APZ, UTC/IANA, civil date, another occurrence, new generation, expiry and missing cache. Android/Robolectric measures the actual compact and detail TextViews on 192/227 dp round viewports at font scales 1.0/1.5/2.0, including reachable action, wrapping and revoked-cache click. PendingIntent test verifies A/B are distinct and old A retains its original target. Existing layout/ambient and other Wear tests remain enabled. Native-graphics previews under wear/build/reports/stay-compact are synthetic test renderings, not physical-device evidence.

Distribution remains blocked pending review/CI and physical verification of the new build: installed version, circular edges and scrolling at enlarged font, tap/details/back, cache refresh/revocation/expiry, AOD/rotary/TalkBack and phone pairing. A screenshot from a previous installed build is not validation of this candidate. No release upload, rollout or new authority is enabled.
