# CrewCheck v13.5.0 - Visual Mobile + Light Theme

## Objetivo

Polimento visual de lançamento para mobile, tema claro, toggles premium e cards de voo sem overflow.

## Correções

- Reforço anti-overflow no app shell.
- Cards, KPIs e grids com `max-width: 100%`, `min-width: 0` e `minmax(0, 1fr)`.
- Menu inferior flutuante preservado com area de scroll segura.
- Tema claro com tokens de superficie, texto, borda e pills.
- Toggles estilo iOS usando gradiente CrewCheck.
- Cards de voo com pills compactas para apresentacao, METAR/TAF e alerta meteorologico ate pouso.
- Status separado de aeronave e matricula.
- Bottom nav principal em portugues.
- Versao atualizada para 13.5.0 no app shell e tela de login.
