## Aceite deste slice

1. O boot registra `/sw.js` sem bloquear o React.
2. O primeiro install prepara o HTML e os assets same-origin referenciados por ele.
3. Navegação sem rede usa o último shell válido.
4. Atualização de worker não chama `skipWaiting()` no install; o coordenador decide quando ativar.
5. APIs e autenticação não são persistidas como shell.
6. Parser, continuidade, regulamentação, financeiro, Radar e Saída Inteligente permanecem fora do diff.
