# CrewCheck v11.0.9 — Próxima programação, escala financeira e visual premium

## Ajustes principais

- Wallpaper aeronáutico discreto aplicado em todo o sistema, preservando legibilidade.
- Tela de importação com botão de PDF mais chamativo, no padrão premium dos botões de assinatura.
- Removido aviso público sobre iFlight/Admin na importação; o usuário vê apenas fluxo de PDF oficial.
- Próxima programação agora avança conforme o decorrer do dia e ignora programações já finalizadas.
- Após finalizar a programação do dia, a Home exibe "A seguir · amanhã" ou a próxima data, sem confundir com hoje.
- Ao abrir a escala, a tela rola automaticamente para o dia/evento ainda vigente ou o próximo evento.
- Escala passa a exibir estimativa de diárias do dia e ganho diário previsto em cada dia.
- Sincronização local entre abas/dispositivos no navegador foi isolada por usuário, evitando que escala de uma conta apareça em outra conta.
- Menu premium de escala reforçado no Android/app mode com atalhos do mesmo padrão das demais telas.
- Mantido iFlight como módulo restrito, sem chamada visual ao usuário comum.
